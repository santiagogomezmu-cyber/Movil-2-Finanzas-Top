# Movil-2-Finanzas-Top
Finanzas Top es una aplicación móvil enfocada en la gestión y control de las finanzas personales. Su objetivo principal es ayudar al usuario a llevar un registro organizado de sus ingresos y gastos, permitiéndole conocer de una manera sencilla cuánto dinero tiene disponible y cómo está utilizando sus recursos.

La aplicación cuenta con funcionalidades como registro e inicio de sesión de usuarios, administración del perfil, registro de ingresos, creación y eliminación de gastos y consulta del historial de movimientos financieros. A medida que el usuario registra sus movimientos, la aplicación puede actualizar la información relacionada con el saldo disponible, facilitando el seguimiento de las finanzas.

Además, la aplicación busca ofrecer una experiencia sencilla para que cualquier usuario pueda registrar sus movimientos sin necesidad de tener conocimientos avanzados sobre administración financiera. La información se presenta de forma organizada mediante diferentes secciones y elementos visuales, permitiendo identificar rápidamente los ingresos, gastos y saldo disponible.

En general, Finanzas Top busca ser una herramienta práctica para que los usuarios tengan un mayor control sobre su dinero, puedan revisar sus movimientos y tengan una visión más clara de su situación financiera. Su diseño combina una interfaz sencilla con diferentes colores y elementos visuales que ayudan a diferenciar los tipos de información y hacen que la aplicación sea más fácil de utilizar.
